# DBMS Subject Submission

The database-design and SQL portion of Smart Billing is maintained in the `sql/` folder.

It contains the database creation script, normalized schema, seed data, CRUD queries, joins, aggregate queries, subqueries, views, stored procedures, functions, triggers, transactions, indexes, reports, and cursor examples.

Start the database from `sql/16_master_script/setup_database.sql`. Application-facing SQL statements are named with `-- QUERY: NAME` sections in `sql/04_crud_queries/`, and are loaded by the Java query loader at runtime.
